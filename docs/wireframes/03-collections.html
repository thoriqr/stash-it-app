03 — Collections

Collections is the collection browser. It lists collections; opening one browses the items inside it. It is a separate destination from the Inbox — the Inbox shows recent saves across collections, Collections shows collections themselves.

ConfirmedUnsorted is a normal row in this list, identified by system_key === "unsorted" — never by its display name, never by type. It is the only protected collection and can never be deleted. D2, ux §1.5, §D.2
DocUnsorted is pinned first under every sort, via a SQL rank — it never appears on a later page. Render the server's order; do not re-sort. D4, ux §2.2
RecNo item counts. GET /collections carries no count and no total; deriving one would cost a request per collection on an unbounded list. ux §4.1, decisions §2.7
Rec There is no POST /collections; a collection is created only by filing an item into a named one. A create button here would have to be faked. ux §4.1, decisions §2.7
